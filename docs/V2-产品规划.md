## 1. 产品方向

v1 解决「真题怎么考」；v2 解决「备考怎么管」：

| 能力 | 一句话 | 载体 |
|---|---|---|
| AI 成绩分析 | 基于历史成绩做能力曲线、分数曲线、薄弱真题定位 | 仪表盘（重做） |
| 备考计划 | 作战计划 + 倒计时 + 自动打卡 + 心得 + AI 昨日总结 | 备考计划页（新增） |
| 备考学习 | 背单词（机械化三模式起步） | 学习中心（推翻重做） |

使用动线：**打开应用 → 仪表盘看数据 → 计划页看今天该干什么 → 机考/背词执行 → 数据回流仪表盘**。

## 2. 导航重构

现有 4 项 → 5 项（`src/components/shell/topbar.tsx`）：

```
现有: 仪表盘 · 机考模拟 · 学习中心(占位卡) · 设置
改为: 仪表盘 · 备考计划 · 机考模拟 · 学习中心(背单词) · 设置
```

| 导航项 | 变化 | 说明 |
|---|---|---|

| 机考模拟 | 不变 | 题库与连考流程保持现状；仪表盘原「题库 tile」挪到这里 |

| 设置 | 不变 | LLM 配置复用（AI 昨日总结要用） |

## 3. 页面设计

### 3.1 仪表盘 · 成绩分析

三段式布局：

**① 能力总览 4 卡**：当前水平（最近一场总分+四科）· 趋势 vs 上次（±band）· 目标差距（读计划表，无计划时显示「未设定」）· 累计模考（场次/本周/用时）。

**② 分数曲线**（recharts LineChart）：

- **切换维度：总分 / 听力 / 阅读 / 写作**（口语无真题数据，不出维度）
- 数据点口径（P6.1 修订）：**总分 = 仅 COMPLETED 完整套卷场次**；**单科 = 场次内成绩 + 单科散考交卷一并统计**（实线实心点 = 场次，虚线空心点 = 散考）
- 雷达口径：各科最近成绩 vs 该科全部交卷均值（含散考）
- 目标分虚线叠加（总分切换时显示总目标线；分科目时显示该科目标线）
- 悬停 tooltip：该场四科 band + 「查看成绩单」链接（`/session/<sessionId>`）
- 无数据时显示空态引导（「先去完成一场模考」→ 机考模拟）

**③ 四科能力雷达**（recharts RadarChart，复用写作批改卡同款）：最近一场 vs 历史均值双系列；无数据维度自动隐藏。

**④ 薄弱真题清单**（巩固练习闭环）：

- 粒度 = 卷 × 科目（paper 级），非单题
- 判定：该卷该科**最近一次 band < 目标分 − 0.5** → 列入；无目标分时用 6.0 兜底
- 排序：离目标差距降序；展示「最近 band / 已做次数 / 目标」
- 「再练一次」按钮直达 `/exam/<examId>`；重做达标自动移出清单
- 口语无真题，不参与

### 3.2 备考计划页

**状态 A · 未开启 → 五步向导**：

1. **考试日期**：考前须知弹窗（§4.2）确认后，弹出**单一日历组件**直选年月日（机考每日可考，不再分「形式→年→月→日」多级筛选）
2. **目标分数**：总分 + 四科（可只填总分，四科留空用总分−0.5 兜底）
   - **英语水平自述（可选文本框，v2.6 新增）**：多行 textarea，用户自由描述自己的英语基础，**限 200 中文字符以内**（前端 maxLength 200 + 计数提示，后端超长校验拒绝）
     - **用途**：文本**原样注入 LLM 提示词**的「当前水平」段，作为生成计划的补充证据；存 `availability_json.englishLevel`（这轮备考的属性），调整计划重算时随重算复用
     - **填写提示**（输入框下方常驻帮助文案）：「这段文字会交给 AI，用于生成更贴合你的备考计划。建议写清：①基础背景（四六级分数 / 考过的雅思成绩 / 学了多久）②自认的强弱项（如听力能听懂但写不出、口语不敢开口）③备考原因（留学 / 移民 / 工作）——越具体，计划越准」
     - **示例 placeholder**：「六级 480；2024 年考过一次雅思总分 5.5（听 5.5 / 读 6 / 写 5 / 说 5）；阅读还行，写作没思路，口语开口困难；为了留学读研」
     - **留空** → LLM 走无自述路径（历史模考数据 / 目标 −1.0 估计）；**默认模板不解析自由文本**（规则引擎只吃结构化参数），此框仅 LLM 路径生效，确认页徽标为「默认模板」时该框不参与
3. **备考节奏**（v2.3 新增）：
   - 备考身份：**全职备考 / 在职备考**（单选）
   - 每天可投入：**0.5–10 小时**（0.5 步进；在职默认 2h，全职默认 6h）
   - 可安排时段（多选）：**上午 / 中午 / 下午 / 晚上**
4. **个人习惯**（v2.4 新增）：
   - 作息：起床时间 / 睡觉时间（时间选择器，默认 07:00 / 23:00）
   - 各科偏好时段（每科单选，可留空）：**背单词 / 口语 / 听力 / 阅读 / 写作** 分别喜欢在上午 / 中午 / 下午 / 晚上
   - 存 `app_settings.study_preferences`（**人的属性，跨计划持久**——下轮计划复用，向导内可改）；全职/在职、小时数、可安排时段是「这轮备考的属性」，留在 study_plans.availability_json
5. **每日任务量（可选）**：背词数/天（听力/阅读/写作/口语量化后续版本加）——申报值并入 `availability_json.dailyWords`（v2.5），不单独设列

生成逻辑：剩余天数 × 目标差距 × 当前水平（含英语自述）× 备考节奏 × 个人习惯 → LLM 产出分阶段作战方案
（基础期/强化期/冲刺期，每阶段给出周任务模板，见 §4.3 提示词设计）→ 用户确认后落库。
LLM 不可用或输出不合法（重试 1 次后仍失败）时**弹窗询问**：
「AI 暂不可用，是否使用默认模板生成计划？」→ 用户同意 → 走 §4.4 规则引擎生成，确认页标注「默认模板」徽标；
用户拒绝 → 停留在当前步，可稍后重试 AI 生成。**不静默降级**（v2.5）。

**状态 B · 作战主页（三栏）**：

| 左栏 | 中栏 | 右栏 |
|---|---|---|
| 倒计时大数字（天 + 日期）+ **考前须知提醒按钮**（ⓘ，悬停/点击显示 §4.2 同一份须知文案，与向导弹窗复用同一组件） | 今日任务清单（来自计划模板，完成态自动勾选） | 打卡日历（月视图） |
| 目标达成进度条（当前 vs 目标） | 打卡规则说明 | 备考心得（写入/查看） |
| 「调整计划」入口 | 学习情况切换：每日/每周/每月 | AI 昨日总结卡片 |

**自由调整**：改考试日期/目标/每日量 → 只重算未来阶段，**不重置已完成打卡与历史**。
换新计划（如考完再战）：旧计划 ARCHIVE，活动与日记保留关联。

**打卡规则**（自动，无需手动点；**规则可配置**，v2.5——默认值硬编码兜底，设置页可改，存 `app_settings.punch_rules`）：

- 默认规则：当日**交卷 ≥1 次**（任何科目）→ 打卡 ✓；当日**背单词 ≥5 个** → 打卡 ✓；
  两者都满足 → 满卡（日历深绿）；仅一项 → 浅绿
- 数据源：study_activities 当日行；判定在查询时用**配置驱动**计算，不物化
- 规则形状（可扩展，后续加维度只加键）：
  `{submissionMin: 1, wordsMin: 5, bothForFull: true}`——后续可扩 `minutesMin`（学习时长）等

**AI 昨日总结**：次日启动程序时（仪表盘首次加载检测 `last_summary_date < 昨天`）触发，**自动只试一次**；
输入 = 昨日活动数据 + 昨日心得；输出 = 总结 + 今日建议，写入昨日日记的 `ai_summary_json`。
失败 → toast 提示**旁留「重跑」按钮**，用户手点重试（手动不受幂等限制，v2.5）。
LLM 未配置时跳过自动触发，AI 卡引导去设置页。成功只在首页提示一次。

### 3.3 学习中心 · 背单词

> 表结构暂不设计（等实施时定），本节只定交互。

- **词库选择**：内置雅思核心词 + CSV 导入（`word,meaning` 每行）
- **三种模式**（机械化背诵，先简单）：
  1. 英→中快刷：看英文四选一
  2. 听音辨词：Web Speech API 播放发音 → 拼写
  3. 中→英拼写：看中文（+音标提示）→ 打字拼英文
- 词进度字段预留 box_level（为 SM-2 记忆曲线留钩子，第一版只记「背过/没背过」）
- 背词数实时写 study_activities（打卡阈值按 punch_rules 配置，默认 ≥5 触发）
- 费曼学习法 / 记忆曲线复习 / 听力精听 / 阅读精读：虚线占位卡，点击 toast「二期开放」

## 4. 考试日期调研与考前须知

### 4.1 调研结论（2026-09 查证）

| 形式 | 规律 | 来源可靠性 |
|---|---|---|
| 纸笔考试 | 历史上全部落在周六；每月约 2–4 场 | 官方（chinaielts.org） |
| 机考 | **几乎每日可考**（除法定假日/系统维护），多数城市一天多场；考前 3 个工作日截止报名 | 官方 |
| 现状 | **2026 年 9 月起中国大陆全面取消纸笔，仅机考**（UKVI 纸笔更早停止） | 第三方（新航道），以官方公布为准 |

**设计决策**：既然以后只有机考且每天都能考，**直接用一个标准的年月日日历组件**选日期，
过去日期禁用（可选日期必须晚于当天），不再需要「形式→年→月→日」多级筛选，
也无需硬编码任何场次数据。

### 4.2 考前须知弹窗（复用组件）

触发场景（两处，共用同一文案与组件）：

1. **向导选考试日期前**：进入 STEP 1 时先弹出须知，用户点「我知道了，去选日期」继续
2. **作战主页倒计时旁**：提醒按钮（ⓘ 图标），点击显示同一份须知（收起式卡片或小弹窗）

须知文案（Markdown 常量，便于维护）：

```text
考前须知
├─ 换题季说明：每年 1 月、5 月、9 月为雅思口语换题季，新题在该月首场考试启用。
│  若想降低口语碰新题的风险，建议避开换题季首场；本应用写作/听读不受影响。
├─ 费用说明：普通雅思与 UKVI 报名费统一 1990 元（以官方最新公布为准）。
├─ 官方报名：请前往教育部教育考试院雅思报名官网 ielts.neea.cn 报名与查询考位。
├─ 考位建议：机考虽每日可考，但热门城市周末考位紧张，
│  建议提前 1–2 个月关注考位释放情况并尽早报名（机考考前 3 个工作日截止）。
└─ 出分时间：机考考后 1–5 天出分，最快 48 小时。
```

（成本/出分等数字以官方最新公布为准，文案集中在常量里，改一处两处生效。）

### 4.3 LLM 提示词设计（生成 phases_json）

**输入注入**（向导参数 + 历史数据，全部来自本地）：

- 考试日期 → 剩余天数/周数（本地算好再注入，不让 LLM 算日期）
- 目标总分 + 四科目标
- 当前水平：有模考记录时注入「最近一场各科 band + 薄弱科」；无记录时写「无模考记录，按目标 −1.0 估计」
- 英语水平自述（v2.6，可选）：向导 STEP2 的自由文本 `availability_json.englishLevel` **原样注入**（**≤200 中文字符**，前端 maxLength + 后端校验双重限制，无需再截断）；未填时此行不出现。提示词方法论中注明：自述与模考数据冲突时以模考数据为准（自述是主观感知，数据是客观成绩）
- 备考节奏：身份（全职/在职）+ 每日小时数 + 可用时段
- 个人习惯（v2.4）：作息（起床 {wakeTime} / 睡觉 {bedTime}）+ 各科偏好时段（{prefLines}，如「背单词→中午、口语→晚上」；未填的科目不注入）

**提示词骨架**（完整文案实施时落在 `src/lib/plan-prompt.ts` 常量）：

```text
你是资深雅思备考规划师，为中国大陆机考考生制定分阶段作战计划。

## 考生信息
- 考试日期 {exam_date}，距今 {days} 天 ≈ {weeks} 周
- 目标：总分 {overall}（听力 {l} / 阅读 {r} / 写作 {w}）
- 当前水平：{level_block}
- 考生自述（原样引用，可能为空）：{englishLevel}
- 备考身份：{mode}；每天可投入 {dailyHours} 小时；可用时段：{slots}
- 个人习惯：起床 {wakeTime} / 睡觉 {bedTime}；偏好：{prefLines}

## 规划方法论（必须遵循）
1. 阶段：基础期(词汇+题型认知) → 强化期(分科专项) → 冲刺期(整套模考+错题复盘)；
   剩余 <3 周可省略基础期，<2 周只保留冲刺期。
2. 时段匹配：碎片时段只放轻任务(背词/泛听)；整块时段(≥1h)放精听/精读/写作/模考；
   在职考生的完整套卷放晚上或周末。
3. 任务量务实：有效学习量 ≈ 可投入小时数 × 70%，宁少勿多；冲刺期只减不加。
4. 量随投入伸缩、差距加权（基准 = 每天 2h）：听读各 2 套/周起步，每多 1h/天各加 1 套/周，
   全职（5–6h/天）听读可达每天 1 套真题；写作按「写→批改→复盘→重写」循环计
   （1 次写作 ≈ 60 分钟作答 + 等量批改复盘），每天 2h 时每周 1–2 次，≥3h/天 或
   写作为最大差距科目时每周 3–4 次；与目标差距最大的科目在强化期任务量再上调。
5. 习惯优先（v2.4）：考生声明的科目偏好时段必须遵守（slot 直接用偏好值）；
   未声明偏好的科目按方法论 2 分配；任务不得安排在睡觉时间之后至起床之前。
6. 自述用法（v2.6）：考生英语自述用于理解背景与主观强弱项；与模考数据冲突时以模考数据为准。

## 输出（严格 JSON，无其他文本）
{"phases":[{"name":"基础期","weeks":[1,2,3],"focus":"词汇打底+听力精听",
  "weeklyTasks":[{"type":"words","count":30,"unit":"个/天","slot":"noon"},
                 {"type":"listening","count":1,"unit":"套/周","slot":"evening"}]}]}
约束：type ∈ words|listening|reading|writing|speaking|set（set=完整套卷）；
weeks 从 1 起连续覆盖 1..{weeks} 不重叠；slot ∈ 考生可用时段；
focus ≤ 20 字；不生成计划外自由文本任务。
```

**关键取舍**：

- `type` 枚举与 `study_activities` 六列（memorized_word_count、四科 submission_count、exam_set_completion_count）一一对应——**LLM 只定「做什么、多少量」，完成判定走既有 upsert 数据**，不发明 app 追踪不了的任务
- 口语纳入 `weeklyTasks` 全集（`type: speaking`，v2.4）：按**未来全集**建模——P8 口语练习上线后 speaking_submission_count 有真实数据，勾选自动生效；当前版本勾选规则豁免 speaking（见 §4.5）
- 输出经 schema 校验（type 枚举/weeks 连续性/slot 合法性），不合法 → 重试一次 → 仍不合法**不静默降级**，返回失败由前端弹窗询问是否用默认模板生成（§3.2 生成逻辑，v2.5）
- 温度低档（与写作批改同策略），保证同参数输出稳定

### 4.4 默认模板（LLM 降级方案）

纯函数查表 + 缩放（基准 = 每天 2h），与 LLM 输出同一 JSON 形状，可单测：

**① 定阶段**（按剩余周数 W）：

| W | 阶段划分 |
|---|---|
| ≥10 周 | 基础 40% / 强化 40% / 冲刺 20%（比例取整，至少各 1 周） |
| 6–9 周 | 基础 2 / 强化 3 / 冲刺 1 |
| 3–5 周 | 基础 1 / 强化 2 / 冲刺 1（去掉基础期则并入强化） |
| <3 周 | 强化 1 / 冲刺 1 |
| <2 周 | 冲刺 1 |

**② 基准任务表**（每天 2h 基准，>2h 按比例放大、<2h 缩小，取整到 0.5）：

| type | 基础期 | 强化期 | 冲刺期 |
|---|---|---|---|
| words（个/天） | 40 | 30 | 20（全职 +10，冲刺只减不加） |
| listening（套/周） | 1 | 2 | 2 |
| reading（套/周） | 1 | 2 | 2 |
| writing（套/周） | 1 | 2 | 1（每日 <1.5h 时强化期降为 1） |
| speaking（次/周，v2.4） | — | 1 | 1（口语练习论「次」不论「套」；P8 上线前数据恒 0，勾选豁免见 §4.5） |
| set（套/周） | — | — | 1（全职模考上午；在职放晚上） |

**缩放示例**（缩放系数 = dailyHours / 2，取整到 0.5）：

- 在职 2h/天 = 表中基准：听读各 1–2 套/周 + 写作 1–2 次/周
- 在职 3h/天（×1.5）：听读各 2–3 套/周，写作 2–3 次/周
- **全职 6h/天（×3）：听读各 3–6 套/周（≈一天 1 套真题）+ 写作 3–4 次/周（每次配等量批改复盘）+ 冲刺期 set 每天 1 套**
- 上限保护：单科 ≤7 套/周（每日刷题也要留复盘时间）；words 上限 80 个/天

**③ 时段分配规则**（v2.4 升级：**科目偏好优先，可用时段回退**；slots 为空且无偏好时全部不填 slot，渲染层灰色显示）：

- 科目偏好（app_settings.study_preferences.subjectSlots）声明了该科时段 → **直接用偏好值**（无可用整块校验，用户偏好即真理）
- 未声明偏好的科目按原规则回退：words → 碎片时段优先（中午 > 晚上 > 上午 > 下午）；listening / reading → 首个整块时段（≥1h 视为整块）；writing → 最长整块时段；set → 上午优先，其次晚上

**作息约束**（v2.4，wake/bed 注入后生效）：作息决定四时段的**起止边界**——上午/中午/下午/晚上按 wake/bed 三等分加午后划分（如 07:00 起 23:00 睡 → 上午 07–11 / 中午 11–14 / 下午 14–18 / 晚上 18–23）；起床晚的「上午」相应后移，「晚上」不得越过 bedTime。作息未填时跳过此约束，用默认边界（07:00 / 23:00）。

**校验兜底**：所有 count 最小 1（words 最小 10）→ 保证任何输入都有非空任务清单；
阶段调整重算时同样走这套规则，只重排未来周。

### 4.5 任务勾选判定（phases_json × study_activities 对照）

今日任务清单的每项按 type 对照当日 activities 数据勾选（查询时计算，不物化）：

| type | 勾选条件（当日） |
|---|---|
| words | memorized_word_count ≥ count |
| listening / reading / writing / speaking | 对应 `*_submission_count ≥ count`（count 为 套/周 时按**本周累计**判定） |
| set | exam_set_completion_count ≥ count（按本周累计） |

**勾选豁免（P8 前）**：口语任务不参与勾选判定（数据恒 0），渲染为「无追踪」灰色样式（信息性展示，不亮红不报未完成）；P8 口语练习上线、speaking_submission_count 有真实写入后自动转为正常勾选，**phases_json 形状不变**。

### 5.2.1 app_settings 新增键 — study_preferences（v2.4）

个人习惯**不建新表**，复用既有 key-value 表 `app_settings`（`key` PK + `value_json`）：

| key | value_json 形状 | 说明 |
|---|---|---|
| `study_preferences` | `{wakeTime, bedTime, subjectSlots}` | 作息 + 各科偏好时段（见 §5.4）；**人的属性，跨计划持久**，下轮计划生成时自动复用；设置页可改，改后不自动重算计划（走「调整计划」显式重算） |

归属对比（为何不放 study_plans）：全职/在职、每日小时数、可安排时段随**这轮备考**变化（换工作/脱产）；作息和科目偏好是**个人长期习惯**，跨计划稳定——分开放，下轮向导少填一半。

## 6. 数据流

```text
交卷(API) ──┬─→ study_activities upsert(对应 *_submission_count +1; 连考完成 exam_set_completion_count +1)
            └─→ (既有) exam_records / exam_sessions
背词(模块) ──→ study_activities upsert(memorized_word_count+1)
心得(表单) ──→ study_journals upsert(journal_date+period)
计划生成   ──→ 读向导参数 + app_settings.study_preferences(习惯) + 历史水平 → LLM/默认模板 → phases_json(用户确认后落库)
启动检测   ──→ AI 昨日总结: 读昨日 activities + journal → LLM → 回写 journal.ai_summary_json
仪表盘     ──→ 读 exam_sessions(曲线/雷达) + exam_records(薄弱清单) + study_plans(目标线)
计划页     ──→ 读 study_plans + study_activities(日历/统计) + study_journals(心得/AI总结)
```
