需要安装 Node.js(≥ 22)

IELTS Copilot 依赖 Node.js 运行,你的机器上未检测到(或版本低于 22)。安装后再双击「启动.command」即可。

  1. 打开官网下载页:nodejs.org/zh-cn/download
  2. 下载 macOS 安装包(.pkg),版本选 22 LTS 或更高
  3. 双击安装(一路继续),完成后新开一个终端窗口执行 node -v 确认输出 ≥ v22
  4. 回到应用文件夹,再次双击 启动.command
前往下载 Node.js

为什么需要 Node:本应用是一个运行在你电脑上的本地网页服务(数据不出本机),Node 是它的运行时。
