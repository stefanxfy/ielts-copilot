## 1. 需求定稿口径（用户原话归纳）

| # | 需求                                              | 地基落点                                                      |
| - | ----------------------------------------------- | --------------------------------------------------------- |
| 1 | 英文文章按**段落**中译英对照                                | `paragraphsJson` 段落级 `{en, zh}`                           |
| 2 | 音频也按**段落**对应，读文章时可**单独听某段**                     | 段落级 mp3 一段一文件，`p.audio`                                   |
| 3 | 翻看某段英文对照中文翻译                                    | 段落卡译文展开/收起                                                |
| 4 | 不认识的生词**加入生词本**                                 | 复用 word_books 体系（§4）                                      |
| 5 | 词库内单词**波浪线**划出，点击弹卡：**音标 / 中文释义 / 构词解析 / 单词读音** | 词库命中管线 + 词卡 Popover（§5），字段全复用 `words.contentJson`，**零新表** |
| 6 | 素材首选从现有**雅思阅读真题**解析导入，注明**出自哪套真题**              | `source=past_paper` + `sourceRefJson`                     |
| 7 | 后续加**打字练习**，素材=阅读库文章                            | 二期预留入口，地基零改动                                              |

设计总原则：**对齐粒度 = 段落**（不是句子、不是整篇）。段落是翻译、音频、播放、对照、打字练习共同的最小复用单元。

## 2. 新增数据表（2 张）

### 2.1 `reading_articles`：文章静态定义

```ts
export const READING_SOURCES = ["past_paper", "web", "manual"] as const;

export interface ReadingSourceRef {
  /** 真题来源:套卷短标识,如 "a-2025jan"(FK 语义但不设外键,删卷不影响阅读库) */
  examSetId?: string;
  /** 单科卷 examId,如 "a-2025jan-reading-test1" */
  examId?: string;
  /** 展示用快照,如 "Cambridge 19 · Test 1" */
  paperTitle?: string;
  /** 该卷第几篇 passage(1 起) */
  passageNo?: number;
}

/** paragraphsJson 单条 —— 段落(翻译/音频/播放/对照的公共对齐单元) */
export interface ReadingParagraph {
  /** 段序号,0 起,全局稳定(重导入保持不变) */
  idx: number;
  en: string;
  /** 段落中文翻译;null = 未生成/生成失败(可重翻补齐) */
  zh: string | null;
  /** 段落音频 web 路径 /audio/reading/<articleId>/p03.mp3;null = 未合成 */
  audio: string | null;
}

export const readingArticles = sqliteTable("reading_articles", {
  /** 幂等导入键:真题源 "a-2025jan-r-t1-p2",web 源 "<source>-<slug>" */
  articleId: text("article_id").primaryKey(),
  title: text("title").notNull(),
  source: text("source", { enum: READING_SOURCES }).notNull(),
  /** 出自哪套真题(past_paper 必填;其余可空)——列表徽标与详情页出处标注的数据源 */
  sourceRefJson: text("source_ref_json", { mode: "json" })
    .$type<ReadingSourceRef>(),
  /** 难度 L1–L4(真题源默认 L3,可手动改级) */
  level: text("level", { enum: ["L1", "L2", "L3", "L4"] }).notNull().default("L3"),
  wordCount: int("word_count").notNull().default(0),
  /** 话题标签 ["environment","education"],列表筛选用 */
  topicTagsJson: text("topic_tags_json", { mode: "json" })
    .$type<string[]>()
    .notNull()
    .default(sql`(json_array())`),
  /** 正文本体:段落平铺数组(一篇 5–13 段,几 KB,整存整取免 join) */
  paragraphsJson: text("paragraphs_json", { mode: "json" })
    .$type<ReadingParagraph[]>()
    .notNull(),
  /** TTS 音色快照(重合成时幂等判据) */
  audioVoice: text("audio_voice"),
  createdAt: int("created_at", { mode: "timestamp" }).notNull().default(sql`(unixepoch())`),
  updatedAt: int("updated_at", { mode: "timestamp" }).notNull().default(sql`(unixepoch())`),
}, (t) => [index("idx_articles_source").on(t.source)]);
```

**字段清单（`reading_articles`）**：

| 字段 | 列名 | 类型 | 约束/默认 | 说明 |
|---|---|---|---|---|
| articleId | `article_id` | TEXT | **PRIMARY KEY** | 幂等导入键：真题源 `"a-2025jan-r-t1-p2"`，web 源 `"<source>-<slug>"`；重导入冲突即跳过 |
| title | `title` | TEXT | NOT NULL | 文章标题 |
| source | `source` | TEXT | NOT NULL，enum | 来源类型：`past_paper`（真题）/ `web`（网页抓取）/ `manual`（手动粘贴） |
| sourceRefJson | `source_ref_json` | TEXT (JSON) | 可空 | 出处快照 `ReadingSourceRef{examSetId?, examId?, paperTitle?, passageNo?}`；`past_paper` 必填，其余可空；列表徽标与详情页「出自某套真题」的数据源；不设外键 |
| level | `level` | TEXT | NOT NULL，default `L3` | 难度 `L1`–`L4`；真题源默认 L3，可手动改级 |
| wordCount | `word_count` | INTEGER | NOT NULL，default 0 | 词数 |
| topicTagsJson | `topic_tags_json` | TEXT (JSON) | NOT NULL，default `[]` | 话题标签数组，如 `["environment","education"]`，列表筛选用 |
| paragraphsJson | `paragraphs_json` | TEXT (JSON) | NOT NULL | 正文本体：段落平铺 `ReadingParagraph[]{idx, en, zh, audio}`；`zh/audio` 为 null 表示未生成（可重翻/重合成补齐）；音频路径 `/audio/reading/<articleId>/p<idx+1>.mp3` |
| audioVoice | `audio_voice` | TEXT | 可空 | TTS 音色快照（重合成时的幂等判据） |
| createdAt | `created_at` | INTEGER (timestamp) | NOT NULL，default `unixepoch()` | 入库时间 |
| updatedAt | `updated_at` | INTEGER (timestamp) | NOT NULL，default `unixepoch()` | 更新时间（LLM 补译 / 重合成时刷新） |

索引：`idx_articles_source (source)`。

设计决策：

- **正文入库是既有原则的例外**：真题「内容不入库」原则针对考卷 HTML（`public/exams/` 静态文件），阅读库正文是学习素材本体，入库（JSON 列）才能支撑段落级随机存取与点词定位。原始真题 HTML 仍留在文件系统，导入脚本记录血缘。
- **一段一 mp3 文件**（`/audio/reading/<articleId>/p<idx+1>.mp3`），不存整篇——单段播放零 seek、失败重合成只补一段、体积按需下载。
- `sourceRefJson` 不设外键：删真题卷不影响阅读库存文，出处标注用快照字段展示即可。

### 2.2 `reading_progress`：阅读进度（动态层）

```ts
export const READING_STATUSES = ["IN_PROGRESS", "COMPLETED"] as const;

export const readingProgress = sqliteTable("reading_progress", {
  id: int("id").primaryKey({ autoIncrement: true }),
  articleId: text("article_id")
    .notNull()
    .references(() => readingArticles.articleId, { onDelete: "cascade" }),
  status: text("status", { enum: READING_STATUSES }).notNull().default("IN_PROGRESS"),
  /** 读到第几段(0 起)——续读定位 */
  lastParagraph: int("last_paragraph").notNull().default(0),
  /** 累计阅读秒数(打卡与统计用) */
  readSec: int("read_sec").notNull().default(0),
  lastReadAt: int("last_read_at", { mode: "timestamp" }),
  createdAt: int("created_at", { mode: "timestamp" }).notNull().default(sql`(unixepoch())`),
  updatedAt: int("updated_at", { mode: "timestamp" }).notNull().default(sql`(unixepoch())`),
}, (t) => [uniqueIndex("uq_reading_progress_article").on(t.articleId)]);
```

**字段清单（`reading_progress`）**：

| 字段 | 列名 | 类型 | 约束/默认 | 说明 |
|---|---|---|---|---|
| id | `id` | INTEGER | **PRIMARY KEY**，autoincrement | 自增主键 |
| articleId | `article_id` | TEXT | NOT NULL，**FK** → `reading_articles.article_id`，`ON DELETE CASCADE` | 所属文章；删文章级联清进度 |
| status | `status` | TEXT | NOT NULL，default `IN_PROGRESS` | 阅读状态：`IN_PROGRESS` 进行中 / `COMPLETED` 已读完（读完即从「继续学习」区消失） |
| lastParagraph | `last_paragraph` | INTEGER | NOT NULL，default 0 | 读到第几段（0 起）——续读定位 |
| readSec | `read_sec` | INTEGER | NOT NULL，default 0 | 累计阅读秒数（打卡与统计用） |
| lastReadAt | `last_read_at` | INTEGER (timestamp) | 可空 | 最后一次打开时间——「继续学习」区排序依据 |
| createdAt | `created_at` | INTEGER (timestamp) | NOT NULL，default `unixepoch()` | 首次打开时间 |
| updatedAt | `updated_at` | INTEGER (timestamp) | NOT NULL，default `unixepoch()` | 进度上报时间 |

索引：`uq_reading_progress_article (article_id)` 唯一索引——一人一篇文章一条进度。

完全对齐「静态定义/动态学习切开」原则：删文章级联清进度。

### 2.3 打字练习（二期预留，本期零建表）

打字练习的素材消费方式 = 读 `reading_articles.paragraphsJson[].en`，逐段打字 + 正确率/速度统计。统计流水属二期新表（如 `typing_sessions`），**本设计不预建**——只预留 `/typing` 路由入口与文章选择器复用（列表数据同源）。

## 3. 真题导入管线（素材首选源）

```
reading-import-paper.mjs
  1. 遍历 papers(subject=reading) → assetsJson.entry 定位 public/exams/<examId>/reading.html
  2. 按 passage 容器切分正文段(容错:无显式段落结构时按 <p> 归并,标题行剔除)
  3. articleId = "<examSetId>-r-t<testNo>-p<passageNo>" 幂等:已存在跳过(断点续传)
  4. LLM 逐段翻译(zh 回填;失败段落 zh=null 进失败清单,不阻塞整篇)
  5. sourceRefJson 写入 {examSetId, examId, paperTitle: papers.title, passageNo}
  6. wordCount/level(默认 L3) 落库 → reading-check 校验(段数>0/zh 覆盖率/血 缘完整)

reading-tts.mjs(复用 synth-audio-xdf 骨架:幂等/续传/失败清单,Python 路径改跨平台探测)
  逐段合成 → /audio/reading/<articleId>/p<idx+1>.mp3 → 回写 paragraphsJson[].audio
```

- 出处标注双呈现：文章列表卡片徽标「Cambridge 19 · T1 · P2」（读 `sourceRefJson`），阅读页标题下方同源灰字。
- 真题源天然自带**官方难度锚**（P1 偏易 → P3 偏难），导入时可按 passageNo 预置 level（P1=L2/P2=L3/P3=L3+），人工改级兜底。

## 4. 生词本：复用词库体系，零新表

| 机制     | 设计                                                                                                                                     |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| 载体     | 固定一本 `word_books(source="custom", bookId="vocabulary", name="生词本")`，首次使用自动创建；`app_settings` 存 `reading.vocabularyBookId` 指向其 id        |
| 加词     | `words` 无该词 → upsert `words(origin="manual")`（仅 word 本体，contentJson 空壳，等 ECDICT 回填管线补富信息）→ `book_word_relation` 挂入生词本（order 取本书 max+1） |
| 已在生词本  | 阅读页打开时随 word-hits 一并返回 `inVocab` 标记，弹卡按钮态「已加入 ✓」                                                                                       |
| 与背单词闭环 | 生词本即普通 custom 词书 → 直接进入既有背单词调度（FSRS），**阅读 → 生词 → 复习全链打通，零新逻辑**                                                                         |

## 5. 词库命中波浪线 + 点词弹卡

### 5.1 命中管线

- **后端**：`GET /api/reading/[id]/word-hits` —— 全文 tokenize（`\b[a-zA-Z']+\b` 归一小写、去 's）→ `IN` 批查 `words.word`（命中即词库有此词）→ 并查 `reading_progress` 同款生词本 relation 得 `inVocab`。返回 `[{ token, wordId, inVocab }]`（一篇约 30–80 命中，单请求轻量）。
- **前端**：渲染时按 token 精确匹配（保留原大小写形态）包 `<span class="vocab-hit">`（波浪线 `text-decoration: underline wavy`，词库命中 + 默认色；生词本已收 + 强调色）。复数/变形先行**精确匹配**，模糊归一（-s/-ed/-ing 还原）作二期增强，避免误划。
- **点词弹卡**：`GET /api/words/lookup?w=<wordId>` 返回整行 words，字段映射全复用现有资产：

| 弹卡区块    | 数据来源                                         | 缺省兜底          |
| ------- | -------------------------------------------- | ------------- |
| 词头 + 音标 | `words.word` + `phoneticUk`（无则 `phoneticUs`） | 音标灰字「暂无」      |
| 单词读音 🔊 | `contentJson.audio.word`（既有 edge-tts 回写）     | 缺失时点击触发按需合成再播 |
| 中文释义    | `contentJson.translation[]`                  | —             |
| 构词解析    | `contentJson.root`（ECDICT 词根拆解）              | 缺失隐藏该区块       |
| 词形/短语   | `contentJson.exchange`                       | 缺失隐藏          |
| 加入生词本   | §4 机制                                        | —             |

## 6. 交互设计

### 6.1 文章列表 `/reading`

- 卡片：标题 + 出处徽标（真题源）+ 级别徽标 + 词数 + 话题标签 + 进度条（`reading_progress`）。
- 筛选：来源（真题/全部）、级别、话题；「继续阅读」置顶最近一篇。

### 6.2 阅读页 `/reading/[articleId]`

- **顶栏**：标题、出处灰字、字号调节、**段落译文开关**（全部展开/全部收起/悬停显示，默认「点段落展开」）。
- **段落卡**（核心交互单元，见线框图）：
  - 左侧 ▶ 按钮：**单独播放本段音频**；连播 = 播完自动下一段，播放中段落左边框高亮 + 自动滚动跟随。
  - 点击段落正文：展开/收起该段中文翻译（对照呈现于英文下方，浅色底）。
  - 词库命中词波浪线，点击弹卡（§5.1）。
  - 段落右上角 ⋯ 菜单：重播 / 复制本段 / （二期）送入打字练习。
- **底部进度条**：段序 / 总段数，退出即存 `reading_progress`。

### 6.3 API 草案

| 路由                            | 方法   | 作用                                  |
| ----------------------------- | ---- | ----------------------------------- |
| `/api/reading`                | GET  | 文章列表（含进度快照）                         |
| `/api/reading/[id]`           | GET  | 文章全文 + 本人进度                         |
| `/api/reading/[id]/progress`  | POST | 上报 lastParagraph / readSec / status |
| `/api/reading/[id]/word-hits` | GET  | 词库命中集 + inVocab 标记                  |
| `/api/reading/[id]/vocab`     | POST | 加生词本（upsert words + relation）       |
| `/api/words/lookup`           | GET  | 词卡数据（音标/释义/构词/读音路径）                 |
