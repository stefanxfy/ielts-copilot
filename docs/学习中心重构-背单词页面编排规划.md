## 2. 页面编排(v1.2 定稿)

### 2.1 一级概念只有两个:「背单词」+「资料库 ▾」

| 概念 | 位置 | 路由 | 状态 | 职责 |
|---|---|---|---|---|
| **背单词** | 导航一级项 | `/learn` | 待开发 | **点击直达认词卡**,背词 + 复习一体;右上角进度两件套;零选词时显示引导页 |
| **单词库** | 资料库下拉第一项 | `/learn/books` | 已有(更名迁入口) | 词书卡片 + 新建/导入;**点词书卡 → 词表浏览** |
| **词表浏览**(单词库内) | 下钻页 | `/learn/books/[bookId]` | 待新建(正式化 vocab-demo) | 词表浏览、试听、看释义;每词「加入/移出背诵计划」勾选 |
| 语法库 / 阅读库 / 视听库 | 资料库下拉 | — | **占位,点击无反应** | 以后再实现 |

v1.1 的「学习台」页面**整体取消**——不做到期队列、不打卡日历、不做词书分行进度条、不做「开始复习」按钮中转。打开背单词就是复习现场,答完即走。

v1.1 计划的独立路由 `/learn/review` **不再需要**:复习 session 直接升为 `/learn` 根路由,内部按状态渲染三种形态(见 §2.2)。

### 2.2 `/learn` 三形态状态机

```
点击「背单词」 → /learn
  ├─ A. 背词计划零选词(没从单词库选过任何词)
  │     → 中央提示页:「请先到单词库制定背词计划」+「去单词库 →」按钮
  │       不渲染认词卡;不显示今日进度条与已背总数
  ├─ B. 有选词,但无今日计划
  │     → 直接展示认词卡,可开始背词 + 复习
  │       右上角只显示「累计已背 N 词」,**不显示今日进度条**
  └─ C. 有选词,且有今日计划
        → 认词卡 + 右上角「今日进度 10/30」进度条 + 「累计已背 N 词」
```

- **今日计划的来源**:每日计划量(设置页学习偏好里的每日新词量)+ FSRS 到期复习词,合成"今日队列"。设置了每日量且今日队列非空,即视为"有今日计划"。
- **累计已背总词数**:word_progress 中已进入学习流程的词总数,三种形态中 B/C 恒显示。

### 2.3 右上角进度两件套(session 内常驻)

```
  今日进度 ▓▓▓▓░░░░ 10/30     累计已背 218 词
```

- 今日进度条:仅形态 C 显示;完成 30/30 后变完成态(如「今日完成 ✓」),仍可自由复习。
- 累计已背:形态 B/C 恒显示,给用户长期成就感锚点。
- 两件套在卡片区右上角,不占正文空间,不弹窗。

**动线**:单词库导词 → 词表选词入计划 → 点「背单词」直达认词卡开背 → 答完一词右上角进度 +1,FSRS 算到期明日再来;零选词用户被中央引导一键送去单词库,选完词回来即是复习现场。

## 3. 资料库下拉(导航右侧新增)

- 四项:

| 菜单项 | 行为 |
|---|---|

## 4. 删除与保留清单

**删除(落地时一次做)**:
- `src/app/(shell)/learn/page.tsx` 现内容(8 卡占位页)→ 被「复习 session(含零选词引导)」重写取代
- v1.1 遗留概念「学习台」:不建页面、不做到期队列/打卡日历/词书分行进度条/开始复习按钮
- topbar「学习中心」label → 「背单词」
- vocab-demo 页头「← 学习中心」返回链接(随 vocab-demo 退役一并处理)

**保留不动**:
- `/learn/books` 全部(页面 + `/api/vocab-book` 系列接口),仅页面标题文案改「单词库」
- `/api/vocab-study-plan`(选词入计划 API 已就绪,词表浏览页直接消费)
- word_progress / word_review_log 数据层与 FSRS 调度(右上角今日进度与累计已背的数据源)
- `vocab-card-policy.ts`(复习 session 选卡型的既定约束)
- 设置页「备考」分区各卡(阈值/配图风格/音色都属于背单词,留在设置页不动)

**退役(条件触发)**:
- `/learn/vocab-demo`——等 `/learn/books/[bookId]` 词表浏览页上线并覆盖其能力(词列表/音标/音频/释义)后删除。

## 5. 实施顺序建议

1. **S1 门户切换**(小):topbar「背单词」改名 + 「资料库 ▾」下拉(单词库实链、三项占位);`/learn` 先落**状态机骨架**——零选词引导形态可用(数据已就绪,纯查询),有词时暂放"复习功能即将上线"极简占位,导航语义先全部正确
2. **S2 单词库下钻**(中):`/learn/books/[bookId]` 词表浏览页正式化 vocab-demo 能力 + 「加入背诵计划」勾选(word_progress 联动);词书卡整体可点;标题文案改「单词库」
3. **S3 复习 session**(大):`/learn` 移植 card-demo 交互(认词卡 + 默写三型 + 音效 + 判分),接 vocab-card-policy 与 FSRS 回写;右上角进度两件套 + 今日进度条显隐逻辑(形态 B/C)
4. **S4 收尾**(小):session 完成态与今日完成徽标;累计已背口径核对;vocab-demo 退役

S1 独立可交付;S2/S3 顺序可互换(S3 也可先行);S4 收尾。
