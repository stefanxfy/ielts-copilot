# 学习中心重构 · 背单词页面编排规划

> 版本 v1.0 · 2026-09-03 · 状态:**规划待拍板,未动手**
> 决策来源:用户拍板——学习中心 6 张占位卡(错题本/专项训练/精听训练/弱项雷达/分数曲线/生词本)全部不需要,学习中心整个页面去掉;聚焦把**背单词**和**词库管理**做好。

![信息架构前后对比](assets/vocab-ia/ia-before-after.png)

## 1. 现状盘点

| 位置 | 现状 | 判定 |
|---|---|---|
| topbar「学习中心」 `/learn` | 8 张功能卡,6 张纯占位(点击仅 toast) | **整页删除** |
| `/learn/books` 词库中心 | 已上线:卡片网格 + 新建/导入弹窗 + 四步进度 | **保留,升级为一级页面** |
| `/learn/vocab-demo` 背单词演示 | P8 垂直切片:词列表 + 详情 + 音频,写死 ielts-core-pilot | 过渡保留,词表浏览页上线后**退役** |
| 顶部导航 | 仪表盘 / 备考计划 / 机考模拟 / 学习中心 / 设置 | 「学习中心」→「背单词」 |

全站对 `/learn` 的引用仅 3 处:topbar 导航项、`learn/page.tsx` 自身、vocab-demo 页头的返回链接——删除成本低,无死链风险(逐处处理)。

## 2. 页面编排方案(推荐 A)

### 方案 A:背单词单入口,四页动线(推荐)

导航只留一个「背单词」入口(挂 `/learn`),底下四个页面各司其职:

| 页面 | 路由 | 状态 | 职责 |
|---|---|---|---|
| **学习台** | `/learn` | 待新建 | 背单词的"家":今日到期队列 N 词、打卡日历、词书进度条、大按钮「开始复习」。学习动力集中在这一页 |
| **词库管理** | `/learn/books` | 已有 | 词书卡片 + 新建/导入弹窗(TTS/生图策略)。入口从学习台顶部放一个「管理词库」次级按钮 |
| **词表浏览** | `/learn/books/[bookId]` | 待新建(正式化 vocab-demo) | 词表浏览、试听、看释义;每词「加入/移出背诵计划」勾选。这是选词的地方 |
| **复习 session** | `/learn/review` | 待开发 | 认词卡 + 默写三型,交互照抄 card-demo 原型,卡型按 vocab-card-policy 抽取 |

**为什么学习台放 `/learn` 而不是词库**:背单词是高频动作(每天打开就点"开始复习"),词库管理是低频动作(导完一次很少动)。高频页面占据一级路由,低频管理页收进二级——这是"学习台为家,词库为库"的编排逻辑。

**动线**:词库导入 → 词表选词入计划 → 学习台看到今日任务 → 进复习 session → 答完回学习台,FSRS 算出明日到期。

### 方案 B:词库为家(备选)

`/learn` 直接就是现在的词库中心(词书卡片即首屏),学习台作为词书卡片上的「继续学习」按钮进入。省一个页面,但今日队列、打卡日历、复习入口没有统一落脚点,每次学习都要先过词书选择——高频动作被低频页面挡在前面。**不推荐**,仅当用户想要"页面越少越好"时选它。

## 3. 删除与保留清单

**删除(方案 A 落地时一次做)**:
- `src/app/(shell)/learn/page.tsx` 现内容(8 卡占位页)→ 被「学习台」重写取代
- topbar「学习中心」label → 「背单词」
- vocab-demo 页头「← 学习中心」返回链接(随 vocab-demo 退役一并处理)

**保留不动**:
- `/learn/books` 全部(页面 + `/api/vocab-book` 系列接口)
- `/api/vocab-study-plan`(选词入计划 API 已就绪,词表浏览页直接消费)
- word_progress / word_review_log 数据层与 FSRS 调度(学习台"今日 N 词"的数据源)
- `vocab-card-policy.ts`(复习 session 选卡型的既定约束)
- 设置页「备考」分区各卡(阈值/配图风格/音色都属于背单词,留在设置页不动)

**退役(条件触发)**:
- `/learn/vocab-demo`——等 `/learn/books/[bookId]` 词表浏览页上线并覆盖其能力(词列表/音标/音频/释义)后删除。删前它是唯一能听音频、看词详情的界面,先留着不碍事。

## 4. 实施顺序建议(拍板后再排任务)

1. **S1 门户切换**(小):topbar 改名;`/learn` 先用一个极简学习台占位(今日到期数 + 开始复习按钮 + 管理词库入口),让导航语义先正确
2. **S2 词表浏览**(中):`/learn/books/[bookId]` 正式化 vocab-demo 的能力 + 「加入背诵计划」勾选(word_progress 联动)
3. **S3 复习 session**(大):`/learn/review` 移植 card-demo 交互(认词卡 + 默写三型 + 音效 + 判分),接 vocab-card-policy 与 FSRS 回写
4. **S4 学习台完整版**(中):打卡日历、词书进度、复习完成回执;vocab-demo 退役

S1 独立可交付;S2/S3 顺序可互换(S3 也可先行,用 vocab-demo 凑合选词);S4 收尾。

## 5. 待拍板问题

1. **方案 A vs B**:推荐 A(学习台为家);若你更想少一个页面选 B。
2. **「背单词」导航名**:就叫「背单词」,还是「词汇」/「单词」?
3. **学习台首屏内容**:最小版(队列+开始按钮)先行,还是直接把打卡日历做进 S1?(建议最小先行,日历归 S4)
4. **vocab-demo 退役时点**:S2 上线即删,还是观察一阵再删?(建议 S3 完成后删,S2 期间留作音频兜底)
