背单词功能 · 素材收集方案

调研日期 2026-09-02 · 所有渠道均经本机实测验证（✅=实测通过）· ielts-copilot docs
结论（TL;DR）：三件套各有免费且可落地的主渠道——词库用 ECDICT（开源、77 万词条、自带 ielts 考试标签）筛出雅思词表；语境例句优先用现成例句库（百字斩例句 JSON），缺漏用 LLM 批量生成（项目已接 LLM，版权最干净、还能定制雅思风格）；发音用 edge-tts（微软神经音色、免费无限量、可调速）批量合成 mp3 本地化。自定义词库走 CSV/JSON 导入 + 导入后自动补全管线。全部素材本地落盘，背单词功能零外部依赖。

五、自定义导入设计（词书 + 加词）

  • 导入格式：第一版支持 CSV（word,meaning[,phonetic]）与 JSON 数组；只填单词也行——导入后自动走补全管线
  • 自动补全管线（导入体验的关键）：本地 ECDICT 查释义/音标/词频 → 缺例句的用 LLM 生成 → edge-tts 合成音频 → 入库。用户拖一份词单进来即得完整可用词书
  • 手动加词：学习中心/阅读中生词「一键加入生词本」走同一管线
  • 数据模型：沿用 v2 极简风格建议两张新表——word_books（词书元信息）+ words（词条，例句等富信息合并 JSON 列，不生硬拆表），后续出正式设计文档再定稿
