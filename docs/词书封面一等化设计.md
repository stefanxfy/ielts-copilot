# 词书封面一等化设计（word_books.cover_image）

> v1.0 · 2026-09-07 · 状态：待评审

## 1. 背景与问题

- `word_books` 表无封面字段（刻意设计：封面是派生展示）。现状封面 = `coverPool[0]`（书内第一个有配图的词图），`coverPool` 由 `/api/vocab-book` GET 现算。
- 「重新生成封面」= 纯前端轮换游标 +1（`coverPool[shift % len]`），游标存 React state，**刷新即失**，且配图池变化后游标指错图。

## 2. 目标

1. 封面选择持久化：刷新 / 重启后保持。
2. 封面升级为一等数据，为后续 AI 按书名生成专属封面（MiniMax image-01，已有依赖）预留存储位。
3. 交互不变：仍是「重新生成封面」一键轮换，无新增操作步骤。

## 3. 列定义

`word_books` 新增一列：

```ts
/** 选定封面图 web 路径(/images/words/…);NULL=未选定,回落封面池首图。未来 AI 封面同列兼容 */
coverImage: text("cover_image"),
```

可空、无默认值。SQLite `ALTER TABLE … ADD COLUMN` 加可空列零风险，不触发表重建。

## 4. 封面回落规则（展示优先级）

```
cover_image 非空  →  用它
      ↓ (NULL 或图失效)
coverPool[0]     →  书内第一个有配图的词图
      ↓ (池空)
通用渐变底图      →  from-muted to-secondary 渐变 div
```

- 「图失效」（路径指向的文件已被重生成/删除）：前端 `<img onError>` 时回落池首，一行兜底，后端不做磁盘校验（本地应用，省每次列表查询的 stat 成本）。
- API 返回结构不变（`coverImage` / `coverPool` 字段名沿用），仅 `coverImage` 语义变为「选定值 ?? 池首」。

## 5. 交互与数据流变更

### 5.1 「重新生成封面」（books/page.tsx）

- 点击 → 轮换游标 +1 → **立即 PUT 落库**（本地 SQLite 写入毫秒级，连点无压力）→ 乐观更新本地 state。
- 初始游标从数据派生：`coverImage` 在 `coverPool` 中的下标（未选定 = 0），不再从 0 起算。
- 空池行为不变：toast 提示，无落库。

### 5.2 API

`/api/vocab-book` 新增 PUT（现文件只有 GET）：

```
PUT /api/vocab-book
{ bookId: string, coverImage: string | null }
```

- 校验：`coverImage` 非空时必须是该书 `coverPool` 内的路径（防任意路径写入，校验成本一次数组 includes）。
- `coverImage: null` 允许（重置为回落语义），本期 UI 不提供重置入口，接口先行。
- 成功返回更新后的该书 summary。

## 6. 迁移步骤

1. `src/db/schema.ts`：`wordBooks` 加 `coverImage` 列（§3）。
2. `npm run db:generate` → 生成 `0004_*.sql` + meta journal/snapshot 自动更新。
3. 无需手工执行：应用启动时 `runMigrations()`（src/db/migrate.ts）按 journal 幂等补应用。
4. 老库兼容：存量行 `cover_image` 全为 NULL，行为与现在完全一致（回落池首）。

## 7. 改动清单

| 文件 | 改动 |
|---|---|
| `src/db/schema.ts` | wordBooks 加 coverImage 列 |
| `src/db/migrations/0004_*.sql` | db:generate 生成 |
| `src/app/api/vocab-book/route.ts` | GET 的 coverImage 语义改回落；新增 PUT |
| `src/app/(shell)/learn/books/page.tsx` | 游标派生自 coverImage；轮换 PUT 落库；img onError 兜底 |

不动的：导入管线（不写 cover_image，保持 NULL = 自动派生）、学习页、words 表。

## 8. 未来扩展（本期不实现）

AI 专属封面：生成图落 `public/images/covers/`，`cover_image` 写该路径——列语义无需变更，「重新生成封面」按钮届时可分「换一张词图 / AI 生成」两个动作。

## 9. 验收标准

- [ ] 轮换封面 → 刷新页面 / 重启应用 → 封面保持
- [ ] 未轮换过的书（cover_image=NULL）显示池首图，与现状一致
- [ ] 选定封面对应图文件被删 → onError 回落池首，不出现破图
- [ ] PUT 传入池外路径 → 400
- [ ] 迁移在已有老库上幂等通过，二次启动不重复执行
