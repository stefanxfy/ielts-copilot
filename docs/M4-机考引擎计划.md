## 数据来源

- `start` route 返回 `paper / sections / passages / questions(含 groupId)/ choices(group 共享)/ writingTasks`,M4-1 补 `passages` 与 `groups.instruction_html`
- DB 12 表不变,只新增 `responses` 表写入路径(已有 attempts 占位)
- 不引入新依赖

## WRITING 决策

- v1 交卷时 **不评写作**:responses 表写入 taskId + raw text,完成页显示 "已提交,写作待人工批改"
- LLM 评写作推后到 M5(避免 V1 引入同步外部 API 阻塞提交)

## 风险

1. **passage HTML 含大量 inline img / table** — 已有 sanitizeHtml,parser 阶段已剥离 script/style。M4-3 渲染时直接 `dangerouslySetInnerHTML`
2. **块题共享 choices 跨 groupId** — start 已正确按 groupId 取,M4-2 复用
3. **倒计时与 prototype 差异** — prototype 倒计时走服务器时,M4 暂用 `durationSec - elapsed`(M3 决策),M4-7 加注释
4. **真机考 UI 高保真度** — 只保证视觉一致 + 真交互,不做声音提示 / 高亮切题动画等 prototype 细节
