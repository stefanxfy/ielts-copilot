> v0.5 · 2026-09-02 · 本轮范围：词书与词条两表 + 关系表。
> **学习进度表（SM-2）暂不设计**，后续单独章节补充。
> 素材来源决策见 `docs/背单词素材收集方案.md`。

## 0. 已拍板决策（用户确认）

| 决策点 | 结论 |
|---|---|
| 词书↔词关系 | **book_word_relation 关联表**（N:M 规范化，不用 wordsJson 数组；表名带 relation 明示关系表身份） |
| words 主键 | **自增 id + unique(word)**（同 papers 模式） |
| 学习进度 | 本轮不设计，后续单独定 |
| examples 例句 | **只用百词斩 join，不接 LLM 生成**（用户明确：版权问题无需顾虑；默认 1 条，schema 支持多条） |
| 单词发音 | edge-tts（英音 Ryan/Sonia 调速，批量合成 mp3 落 `public/audio/words/`） |
| 词频 bncRank/frqRank | **收回 contentJson**（与其它展示属性归一；高频筛选用 `json_extract` 或应用层 sort） |

## 1. 设计原则（对齐 v3.1 全库哲学）

- **静态与动态一刀切**：words / word_books / book_word_relation 全是静态定义（导入写一次），学习状态后续独立成表
- **词全局唯一共享**：两本词书同含 abandon → words 只存一行内容，book_word_relation 各挂一条关联；进度（后续）全局一份，A 书学会 B 书自动认识
- **内容不入库的例外**：音频 mp3 留文件系统（`public/audio/words/`），库里只存路径——同「真题 HTML 不入库」惯例
- **JSON 列合并富信息**：释义/例句/词根等展示型内容合并 contentJson 一列，不生硬拆列
- **不冗余衍生字段**：列表页词数 `count(book_word_relation)` 实时算；写状态数 `count(word_progress where status=KNOWN)` 实时算——避免 wordCount/knownCount 与事实漂移

## 2. word_books — 词书定义（1 行 = 一本词书）

| 列 | 类型 | 约束 | 语义 |
|---|---|---|---|
| id | int | PK 自增 | |
| bookId | text | unique notNull | 词书英文短标识（`ielts-core` / `custom-20260902`），幂等导入键，同 examSetId 模式 |
| name | text | notNull | 展示名「雅思核心词汇」 |
| description | text | 可空 | 词书说明（来源、适用人群） |
| source | text | enum(`builtin`/`custom`) notNull | 内置（管线导入）/ 用户导入 |
| createdAt / updatedAt | int ts | notNull 默认 now | |

> 不冗余 wordCount：列表页显示词数 `count(book_word_relation)` 即可，单机 8k 行量级无压力，避免两处维护漂移。

## 3. words — 词条内容（1 行 = 一个词，全局唯一）

| 列 | 类型 | 约束 | 语义 |
|---|---|---|---|
| id | int | PK 自增 | 被引用键 |
| word | text | unique notNull | 单词本体（小写归一，模糊匹配在应用层做） |
| phoneticUk / phoneticUs | text | 可空 | 英/美音标（百词斩 accent → 落 Uk；美式后续从 ECDICT phonetic_us 补） |
| contentJson | text json | notNull | 富信息合并列，契约见 §5 |
| origin | text | enum(`ecdict`/`baicizhan`/`import`/`manual`) notNull | 内容血缘：ECDICT 管线 / 百词斩 join / 用户导入携带 / 手动加词 |
| createdAt / updatedAt | int ts | notNull 默认 now | |

> **不在表层冗余展示属性**：词频等数字列入 `contentJson.bncRank/frqRank`，由应用层或 `json_extract(contentJson,'$.bncRank')` 处理——保持表瘦、避免「数据搬家时漏列」。

## 4. book_word_relation — 关系表（1 行 = 某词书的第 N 个词）

| 列 | 类型 | 约束 | 语义 |
|---|---|---|---|
| bookId | int | FK → word_books.id **cascade** notNull | 删词书级联清关联（删词书重导是合法操作） |
| wordId | int | FK → words.id **restrict** notNull | 有词书引用的词条不许删（防误删共享内容） |
| order | int | notNull | 词在本书中的序号（0 起，词序即默认学习序） |
| | | **unique(bookId, wordId)** | 同词不重复入书 |
| | | **unique(bookId, order)** | 序号不撞（保序重排安全） |

> 索引：`index(bookId)`（取整本书按序读）、`index(wordId)`（查词被哪些书收录）。

## 5. contentJson 契约（words 富信息）

```ts
interface WordContent {
  /** 中文释义（多行，百词斩 mean_cn 拆 "；" ） */
  translation: string[];
  /** 英文释义（可空，百词斩 mean_en） */
  definition?: string[];
  /**
   * 例句。默认 1 条（来自百词斩 join），schema 支持多条无上限；
   * 字段：en 原句 / cn 中译 / audio 例句音频路径（可空）
   */
  examples: { en: string; cn?: string; audio?: string }[];
  /** 词根拆解（wordroot.txt，如 "port = carry → import/export/transport"） */
  root?: string;
  /** 词形变化（百词斩 sentence_phrase / ECDICT exchange 原串） */
  exchange?: string;
  /** 单词发音路径 /audio/words/abandon.mp3（文件在 public/audio/words/） */
  audio?: { word?: string };
  /** 柯林斯星级 1–5（可空，ECDICT 补） */
  collins?: number;
  /** 考试标签 ["ielts","toefl"]（ECDICT tag 拆分） */
  tags?: string[];
  /** BNC 词频排名（数字越小越常用；可空，ECDICT 补） */
  bncRank?: number;
  /** 当代语料词频排名（数字越小越常用；可空，ECDICT 补） */
  frqRank?: number;
}
```

### 5.0 字段分类速查（用户视角）

| 字段 | 类型 | 来源 | 主要用途 |
|---|---|---|---|
| `translation` | string[] | 百词斩 mean_cn | 学习页/复习卡正面的中文释义 |
| `definition` | string[]? | 百词斩 mean_en | 高级模式展示英文释义、写作英解参考 |
| `examples` | {en,cn?,audio?}[] | 百词斩 sentence+sentence_trans | 学习页/复习卡语境背单词用，辅助记忆 |
| `root` | string? | ECDICT wordroot.txt 词根表 | 词根词缀法批量记词时展示 |
| `exchange` | string? | 百词斩 sentence_phrase / ECDICT exchange | 短语搭配、词形变化速查 |
| `audio.word` | string? | edge-tts 合成 | 学习页/复习卡点喇叭播放单词 |
| `collins` | number? | ECDICT 1–5 星 | 学习中心标识「柯林斯星级」标签（高频权威性参考） |
| `tags` | string[]? | ECDICT 考试标签 | 词书分类筛选用（ielts/toefl/cet4…） |
| `bncRank` | number? | ECDICT bnc 排名 | 高频词排序：自学列表/默认学习序「先高频后低频」 |
| `frqRank` | number? | ECDICT frq 排名 | 当代词频排序，反映当前英语实际使用频率 |

**分组维度**：
- **展示型**（用户直接看到）：translation / definition / examples / root / exchange / audio.word
- **元数据型**（系统辅助）：collins / tags / bncRank / frqRank
- **承载型**（管线追溯）：examples[].audio 等子字段

> 字段命名沿用百词斩与 ECDICT 原 schema（mean_cn→translation、accent→phoneticUk、bnc/frq→bncRank/frqRank），保持上游解析层与落库字段一一对应，管线不用二次翻译。

### 5.1 examples 数据来源（已实测）

**唯一来源**：`lyc8503/baicizhan-word-meaning-API`（开源，10927 词已解析好，jsDelivr CDN 国内稳定）
- 入口：`https://cdn.jsdelivr.net/gh/lyc8503/baicizhan-word-meaning-API/data/list.json`
- 单词接口：`https://cdn.jsdelivr.net/gh/lyc8503/baicizhan-word-meaning-API/data/words/<word>.json`
  （文件名特殊字符 `\ / : * ? " | ` 和空格要替换为 `_`）
- 字段：`accent` 音标 / `mean_cn` 中释 / `mean_en` 英释 / `sentence` 例句 / `sentence_trans` 中译 / `sentence_phrase` 重点短语 / `word_etyma` 词源 / `cloze_data` 音节填空

**默认行为**：百词斩有 sentence → 压 1 条进 `examples[0]`；sentence 为空 → `examples = []`，下次再试（管线幂等重跑可补全）。

**无版权顾虑**：用户已确认版权问题本项目无需考虑（自用学习 App），不需 LLM 二次包装、不二次分发。

**未来扩展性**：schema 允许 examples 多条，未来如想加第二条例句（来自其他源或人工加词），直接 append 即可，无需改表结构。

## 6. 数据流（导入管线 → 三表）

```
素材管线产出 bundle（JSON）
  ├─ word_books         upsert（bookId 幂等）
  ├─ words              upsert（word 幂等；已存在则仅在内容为空时补全，不覆盖用户已有内容）
  ├─ book_word_relation delete+insert（按 bookId 整书重挂，order 重排）
  └─ edge-tts 异步任务  单词发音 mp3 落 public/audio/words/<word>.mp3，回写 words.contentJson.audio.word
```

**百词斩 join 步骤**（在 `applyWordBundle()` 内串行）：
```
1. ECDICT 拉词 + 落 words（contentJson 含 translation/definition/tags/collins/root）
2. 按 words 行去重,逐词 GET jsdelivr 百词斩单词 JSON（带超时+重试+失败跳过）
3. 命中: 取 sentence+sentence_trans 压一条入 examples;不命中: examples=[]
4. 调 edge-tts 合成单词音频(异步批量),落盘后回写 contentJson.audio.word
```

- **重复导入幂等**：同 bookId 再导 → 词书行更新、关联整组替换、词书内词集合变化正确反映
- **词不删**：关联 cascade 走掉，words 行残留无害（下次任何书用到自动复用）
