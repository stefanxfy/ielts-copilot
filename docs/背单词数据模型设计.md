# 背单词数据模型设计 · word_books / words / book_word_relation + word_progress

> v0.6 · 2026-09-02 · 本轮范围：词书 + 词 + 关系 + **学习进度（SM-2 调度）四表**。
> 素材来源决策见 `docs/背单词素材收集方案.md`。

## 0. 已拍板决策（用户确认）

| 决策点 | 结论 |
|---|---|
| 词书↔词关系 | **book_word_relation 关联表**（N:M 规范化，不用 wordsJson 数组；表名带 relation 明示关系表身份） |

| 学习进度 | **word_progress 表 + SM-2 调度**（per-word 全局唯一,FK cascade from words,score 0-5,q<3 重置） |

## 1. 设计原则（对齐 v3.1 全库哲学）

- **静态与动态一刀切**：words / word_books / book_word_relation 全是静态定义（导入写一次），学习状态后续独立成表
- **词全局唯一共享**：两本词书同含 abandon → words 只存一行内容，book_word_relation 各挂一条关联；进度（后续）全局一份，A 书学会 B 书自动认识
- **内容不入库的例外**：音频 mp3 留文件系统（`public/audio/words/`），库里只存路径——同「真题 HTML 不入库」惯例
- **JSON 列合并富信息**：释义/例句/词根等展示型内容合并 contentJson 一列，不生硬拆列
- **不冗余衍生字段**：列表页词数 `count(book_word_relation)` 实时算；写状态数 `count(word_progress where status=KNOWN)` 实时算——避免 wordCount/knownCount 与事实漂移

## 2. word_books — 词书定义（1 行 = 一本词书）

| 列 | 类型 | 约束 | 语义 |
|---|---|---|---|
| id | int | PK 自增 | |
| bookId | text | unique notNull | 词书英文短标识（`ielts-core` / `custom-20260902`），幂等导入键，同 examSetId 模式 |
| name | text | notNull | 展示名「雅思核心词汇」 |

## 4. book_word_relation — 关系表（1 行 = 某词书的第 N 个词）

| 列 | 类型 | 约束 | 语义 |
|---|---|---|---|
| bookId | int | FK → word_books.id **cascade** notNull | 删词书级联清关联（删词书重导是合法操作） |
| wordId | int | FK → words.id **restrict** notNull | 有词书引用的词条不许删（防误删共享内容） |
| order | int | notNull | 词在本书中的序号（0 起，词序即默认学习序） |
| | | **unique(bookId, wordId)** | 同词不重复入书 |
| | | **unique(bookId, order)** | 序号不撞（保序重排安全） |

> 索引：`index(bookId)`（取整本书按序读）、`index(wordId)`（查词被哪些书收录）。

## 5. contentJson 契约（words 富信息）

```ts
interface WordContent {
  /** 中文释义（多行，百词斩 mean_cn 拆 "；" ） */
  translation: string[];
  /** 英文释义（可空，百词斩 mean_en） */
  definition?: string[];
  /**
   * 例句。默认 1 条（来自百词斩 join），schema 支持多条无上限；
   * 字段：en 原句 / cn 中译 / audio 例句音频路径（可空）
   */
  examples: { en: string; cn?: string; audio?: string }[];
  /** 词根拆解（wordroot.txt，如 "port = carry → import/export/transport"） */
  root?: string;
  /** 词形变化（百词斩 sentence_phrase / ECDICT exchange 原串） */
  exchange?: string;
  /** 单词发音路径 /audio/words/abandon.mp3（文件在 public/audio/words/） */
  audio?: { word?: string };
  /** 柯林斯星级 1–5（可空，ECDICT 补） */
  collins?: number;
  /** 考试标签 ["ielts","toefl"]（ECDICT tag 拆分） */
  tags?: string[];
  /** BNC 词频排名（数字越小越常用；可空，ECDICT 补） */
  bncRank?: number;
  /** 当代语料词频排名（数字越小越常用；可空，ECDICT 补） */
  frqRank?: number;
}
```

### 5.0 字段分类速查（用户视角）

| 字段 | 类型 | 来源 | 主要用途 |
|---|---|---|---|
| `translation` | string[] | 百词斩 mean_cn | 学习页/复习卡正面的中文释义 |
| `definition` | string[]? | 百词斩 mean_en | 高级模式展示英文释义、写作英解参考 |
| `examples` | {en,cn?,audio?}[] | 百词斩 sentence+sentence_trans | 学习页/复习卡语境背单词用，辅助记忆 |
| `root` | string? | ECDICT wordroot.txt 词根表 | 词根词缀法批量记词时展示 |
| `exchange` | string? | 百词斩 sentence_phrase / ECDICT exchange | 短语搭配、词形变化速查 |
| `audio.word` | string? | edge-tts 合成 | 学习页/复习卡点喇叭播放单词 |
| `collins` | number? | ECDICT 1–5 星 | 学习中心标识「柯林斯星级」标签（高频权威性参考） |
| `tags` | string[]? | ECDICT 考试标签 | 词书分类筛选用（ielts/toefl/cet4…） |
| `bncRank` | number? | ECDICT bnc 排名 | 高频词排序：自学列表/默认学习序「先高频后低频」 |
| `frqRank` | number? | ECDICT frq 排名 | 当代词频排序，反映当前英语实际使用频率 |

**分组维度**：
- **展示型**（用户直接看到）：translation / definition / examples / root / exchange / audio.word
- **元数据型**（系统辅助）：collins / tags / bncRank / frqRank
- **承载型**（管线追溯）：examples[].audio 等子字段

> 字段命名沿用百词斩与 ECDICT 原 schema（mean_cn→translation、accent→phoneticUk、bnc/frq→bncRank/frqRank），保持上游解析层与落库字段一一对应，管线不用二次翻译。

## 6. 数据流（导入管线 → 三表）

```
素材管线产出 bundle（JSON）
  ├─ word_books         upsert（bookId 幂等）
  ├─ words              upsert（word 幂等；已存在则仅在内容为空时补全，不覆盖用户已有内容）
  ├─ book_word_relation delete+insert（按 bookId 整书重挂，order 重排）
  └─ edge-tts 异步任务  单词发音 mp3 落 public/audio/words/<word>.mp3，回写 words.contentJson.audio.word
```

**百词斩 join 步骤**（在 `applyWordBundle()` 内串行）：
```
1. ECDICT 拉词 + 落 words（contentJson 含 translation/definition/tags/collins/root）
2. 按 words 行去重,逐词 GET jsdelivr 百词斩单词 JSON（带超时+重试+失败跳过）
3. 命中: 取 sentence+sentence_trans 压一条入 examples;不命中: examples=[]
4. 调 edge-tts 合成单词音频(异步批量),落盘后回写 contentJson.audio.word
```

- **重复导入幂等**：同 bookId 再导 → 词书行更新、关联整组替换、词书内词集合变化正确反映
- **词不删**：关联 cascade 走掉，words 行残留无害（下次任何书用到自动复用）

## 8. word_progress — 学习进度表（1 行 = 一个词的 SM-2 调度状态）

### 8.1 设计原则

- **per-word 全局唯一**：与 words 表 1:1（每个词对应一份进度,跨词书共享——A 书里学会了 B 书里自动认识,与词全局共享一脉相承）
- **静态 / 动态一刀切**：words 是内容定义(导入写一次),word_progress 是学习历史(每次复习都写)——遵循 v3.1 全库哲学
- **新增一行 = 第一次评分**:首次评分时 INSERT;之后每次评分 UPDATE
- **删除级联**:FK words.id **cascade**——删 words 行进度自动走掉(理论上 words 不该被删,cascade 是兜底)

### 8.2 表结构

```ts
word_progress = {
  wordId:        int PK FK → words.id (cascade),       // 进度与词 1:1 共享
  /** 当前状态:LEARNING/REVIEWING/KNOWN/IGNORED */
  status:        text enum(LEARNING|REVIEWING|KNOWN|IGNORED) notNull default "LEARNING",
  /** SM-2 ease factor,初始 2.5,下限 1.3 */
  ease_factor:    real notNull default 2.5,
  /** 间隔天数(下次到期的天数) */
  interval_days:    int notNull default 0,
  /** 连续正确次数(答对+1,答错 q<3 重置为 0) */
  repetitions:    int notNull default 0,
  /** 累计答错次数(lapse 计数) */
  lapses:        int notNull default 0,
  /** 累计有效评分次数(过滤 q=0 全黑等) */
  total_reviews:    int notNull default 0,
  /** 下次到期日 YYYY-MM-DD(本地时区;学习页 dueDate <= today 即要背) */
  due_date:        text notNull default "1970-01-01",
  /** 最后评分时间 epoch(毫秒) */
  last_reviewed_at: int notNull default 0,
  createdAt / updatedAt: int ts notNull default now,
}
索引: index(due_date, status)  // 到期复习队列查询(经典热点)
       index(status, due_date)  // 按状态分组拉取
```

### 8.3 SM-2 算法实现

```ts
/**
 * q: 0=完全忘记 / 3=答对吃力 / 5=完美回忆
 * UI 默认给三档(对照): q=5 认识 / 3 模糊 / 0 不认识
 */
function applyReview(p: WordProgress, q: 0|1|2|3|4|5, today: string): WordProgress {
  const ef = p.ease_factor;
  let nextEf = ef + (0.1 - (5 - q) * (0.08 + (5 - q) * 0.02));
  if (nextEf < 1.3) nextEf = 1.3;

  let nextInterval: number;
  let nextReps: number;
  let nextStatus: string;
  let nextLapses = p.lapses;

  if (q < 3) {
    // 答错:重置间隔与连续次数,累计 lapse
    nextInterval = 1;
    nextReps = 0;
    nextLapses = p.lapses + 1;
    nextStatus = "LEARNING";
  } else {
    if (p.repetitions === 0) nextInterval = 1;
    else if (p.repetitions === 1) nextInterval = 6;
    else nextInterval = Math.round(p.interval_days * nextEf);
    nextReps = p.repetitions + 1;
    // 状态机:连续 3 次答对 → REVIEWING,连续 6 次 + interval≥21 → KNOWN
    nextStatus = nextReps >= 6 && nextInterval >= 21 ? "KNOWN" : "REVIEWING";
  }

  return {
    ...p,
    ease_factor: nextEf,
    interval_days: nextInterval,
    repetitions: nextReps,
    lapses: nextLapses,
    status: nextStatus,
    due_date: addDays(today, nextInterval),
    last_reviewed_at: Date.now(),
    total_reviews: p.total_reviews + 1,
    updatedAt: new Date(),
  };
}
```

### 8.4 状态机

```
(无 row) → 首次评分 → LEARNING
LEARNING ──q≥3 连续 3 次──→ REVIEWING
LEARNING ──q<3──→ LEARNING (重置 reps=0)
REVIEWING ──q<3──→ LEARNING (降级 + 重置 reps)
REVIEWING ──q≥3 连续 6 次 + interval≥21──→ KNOWN
KNOWN ──q<3──→ LEARNING (忘掉,降回 LEARNING)
任意状态 ──用户标记 IGNORED──→ IGNORED (不再调度)
```

## 9. 学习队列查询

```sql
-- 今日到期 + 学习中
SELECT w.*,, p.status, p.ease_factor, p.due_date, p.repetitions
FROM words w
INNER JOIN word_progress p ON p.word_id = w.id
INNER JOIN book_word_relation r ON r.word_id = w.id
WHERE r.book_id = :bookId
  AND p.status IN ('LEARNING', 'REVIEWING')
  AND p.due_date <= :today
ORDER BY
  CASE p.status WHEN 'LEARNING' THEN 0 WHEN 'REVIEWING' THEN 1 END,
  p.due_date ASC
LIMIT :batchSize;
```

要点:
- **不冗余 wordCount/knownCount**:列表页实时 `count(...)`,与 v3.1 一致
- **新增词(N 行)无 word_progress 行**:首次评分前不在到期队列;UI 首次接触时"插入初始进度(status=LEARNING, due_date=today, reps=0)"
- **IGNORE 状态不出现在队列**:WHERE status IN ('LEARNING','REVIEWING')
- **批次大小**:学习页默认拉 20 词一批(SM-2 推荐每日 20 新词;符合 SuperMemo "40min/day" 经验)

## 10. 与 study_activities 联动

study_activities.memorizedWordCount 已预留(P7 设计即有此列),本表定稿后:

```ts
async function persistReview(wordId: number, q: 0|1|2|3|4|5) {
  const today = ymd();
  await db.transaction(async (tx) => {
    const prog = tx.select().from(wordProgress).where(eq(wordProgress.wordId, wordId)).get()
      ?? createInitialProgress(wordId, today); // 首次评分初始化
    const next = applyReview(prog, q, today);
    tx.update(wordProgress).set(next).where(eq(wordProgress.wordId, wordId)).run();
    // 状态转换触发 memorizedWordCount
    if (prog.status !== 'KNOWN' && next.status === 'KNOWN') {
      tx.insert(studyActivities)
        .values({ activityDate: today, memorizedWordCount: 1 })
        .onConflictDoUpdate({
          target: studyActivities.activityDate,
          set: { memorizedWordCount: sql`memorized_word_count + 1` },
        })
        .run();
    } else if (prog.status === 'KNOWN' && next.status !== 'KNOWN') {
      tx.update(studyActivities)
        .set({ memorizedWordCount: sql`max(0, memorized_word_count - 1)` })
        .where(eq(studyActivities.activityDate, today))
        .run();
    }
  });
}
```
