# 背单词功能 · 素材收集方案

> 调研日期 2026-09-02 · 所有渠道均经本机实测验证（✅=实测通过）· ✅=可再分发 ⚠️=仅限本机自用

## 结论（TL;DR）

三件套各有免费且可落地的主渠道：

- **词库**：用 **ECDICT**（开源、77 万词条、自带 ielts 考试标签）筛出雅思词表
- **语境例句**：优先用现成例句库（百词斩例句 JSON），缺漏用 **LLM 批量生成**（项目已接 LLM，版权最干净、还能定制雅思风格）
- **发音**：用 **edge-tts**（微软神经音色、免费无限量、可调速）批量合成 mp3 本地化

自定义词库走 CSV/JSON 导入 + 导入后自动补全管线。全部素材本地落盘，背单词功能零外部依赖。

## 二、语境例句来源

| 来源 | 说明 | 版权 |
|---|---|---|
| **百词斩例句表**（zhenghaoyang24/english-vocabulary） | `tb_voc_examples.json`：例句 en+中译，按 wordid 与词条表关联（词条表含雅思书）；覆盖率高、真人编写的教学例句 | ⚠️ 个人学习用 |
| **dictionaryapi.dev**（Wiktionary） | 免 key 免费 REST API：释义/例句/**真人音频 URL**/同义反义。实测可用但偶尔空响应（需重试+缓存）。适合「补漏」与「按需查询」，不适合全量依赖 | ⚠️ CC BY-SA 3.0 署名 |
| **LLM 批量生成**（推荐主力） | 项目已接 LLM（config.json）。按「雅思真题风格（学术场景/图表描述/观点论证）」批量生成例句+中文翻译+词形搭配，一次生成全量本地化。质量可控、风格统一、**版权完全干净**、可按用户弱项定制（如写作高频词给议论文句式） | ✅ 自有内容 |

## 三、发音音频来源

| 来源 | 说明 | 版权 |
|---|---|---|
| **edge-tts**（推荐主力） | 微软 Edge 神经网络语音的 Python 封装（v7.2.8，LGPL）：**免费、无 key、无配额**。`en-GB-RyanNeural / SoniaNeural` 英音，支持调速（单词可放慢 10%）。单词、例句都能合成，批量脚本一次跑完落 `public/audio/` | ✅ 音频自用无虞 |
| gstatic 真人录音 | dictionaryapi.dev 返回的真人音频（实测 200，7.5KB/词）。覆盖不全、URL 带日期版本会失效——只适合「批量下载缓存进本地」，不要在线直连播放 | ⚠️ 缓存自用 |
| Web Speech API | 浏览器原生 `speechSynthesis`，零素材成本兜底方案；音色依赖系统（macOS 尚可、Windows 参差），可作 edge-tts 缺漏时的在线兜底 | ✅ 无限制 |

## 四、推荐素材管线（一条流水线跑通）

```
① 拉 ECDICT ──→ ② 补例句 ──→ ③ 合成音频 ──→ ④ 入库
codeload 源码包    百词斩例句 join    edge-tts en-GB     词书/词条进主库
stardict.7z 解压   缺漏 LLM 生成     批量 mp3 落        音频路径入列
tag 筛 ielts       （雅思风格         public/audio/      功能零外网依赖
~5-8k 词           en+cn）           words/
```

**预估产出**：雅思核心词书 5-8k 词 ×（释义+音标+2 例句+2 音频）≈ 音频 1-2GB 磁盘、跑批一次约 1-2 小时（edge-tts 并发限速下）。

> ⚠️ 先跑 **500 词垂直切片**验证全链路，再放量。

## 五、自定义导入设计（词书 + 加词）

- **导入格式**：第一版支持 CSV（`word,meaning[,phonetic]`）与 JSON 数组；只填单词也行——导入后自动走补全管线
- **自动补全管线**（导入体验的关键）：本地 ECDICT 查释义/音标/词频 → 缺例句的用 LLM 生成 → edge-tts 合成音频 → 入库。用户拖一份词单进来即得完整可用词书
- **手动加词**：学习中心/阅读中生词「一键加入生词本」走同一管线
- **数据模型**：沿用 v2 极简风格建议两张新表——`word_books`（词书元信息）+ `words`（词条，例句等富信息合并 JSON 列，不生硬拆表），后续出正式设计文档再定稿
