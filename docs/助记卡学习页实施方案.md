# /learn 助记卡渲染与交互 · 详细实施方案

> v1.0（2026-09-06）· 上游设计：`docs/单词助记系统设计.md` v2.5
> 原则：**现有 /learn 一切交互零破坏**（三键评分、方向键、默写卡提示/判分/自动跳词全部原样）；助记卡是**叠加层**，不是改造。

---

## 0. 目标与边界

**目标**：在 `/learn` 复习页补上设计文档 v2.5 定稿的四卡助记辐射（构词解析 / 派生·词性·近义 / 读音解析 / 真实语境）的渲染与交互，效果对齐原型 `prototype/vocab/card-demo/radial.html`。

**硬边界（不动清单）**：

| 现有交互 | 约束 |
| --- | --- |
| 认词卡三键（不认识/模糊/认识） | 点击行为、按钮态、幂等锁定、认识自动跳词——一行不改 |
| 默写卡（三型、两级提示、查看答案、判分音效、900ms 自动跳词） | 全部原样 |
| 方向键 ArrowLeft/Right（含输入聚焦不抢键、右进需先背过） | 全局监听逻辑原样保留 |
| 主卡布局（fitWord 收缩、slide-nav 对齐、recog-stage） | 视觉与几何零变化 |

**允许新增**：一个「收起/打开助记」的手动开关按钮；触发条件满足时自动展开的助记辐射层。

## 1. 现状盘点（代码事实）

### 1.1 /learn 页面

- 核心文件：`src/app/(shell)/learn/page.tsx`（1291 行，单文件含 RecogCard / DictationCard / 评分 / 导航 / 音效）。
- 主列 `max-w-[760px]`，卡片 `max-w-[400px]`；方向键按钮用 `useLayoutEffect` 按 `anchorRef`（单词行）几何中心对齐。
- 触发点已存在且语义清晰，可直接挂钩：
  - 认词卡：`rateRecog()` 中 `r === "hard" | "again"` 分支（L477 `setRecogRevealed(true)` 处）；`good` 分支零辐射。
  - 默写卡：`gradeSpell()` 判错分支（L515 `sfxWrong()` 后）与 `hintSpell()` 的「查看答案」分支（L533）。
- 键盘：`useEffect` document 级监听（L425-434），输入框聚焦时不抢——overlay 打开时的键盘策略见 §2.3。

### 1.2 数据链路（利好：API 几乎零改动）

- `src/lib/vocab-review.ts` L173 `const content = r.contentJson` —— **words.contentJson 原样透传前端**。
- 因此库里 contentJson 一旦有 `syl / morph / derives / contexts` 字段，GET /api/vocab-review 自动带出；前端只需在 `page.tsx` 的 `WordContent` TS 接口补可选字段 + `QueueItem` 透传，**API 层不改一行**。
- 字段现状：生成管线（P1.1–P1.6，四次 LLM 调用 + TTS 音频落盘）**尚未实现**，正式库目前无这四个字段 → 渲染层必须按「字段缺失降级」设计，并允许脚本注入少量真实数据验收（§6 M2）。

### 1.3 原型资产（移植源）

- `radial.js` 1133 行：词数据 + `radiateMn`（stagger 弹簧动画、起飞透明防 mini 卡闪现）+ `buildMnContent`（四卡渲染、词组高亮 hiColl）+ `drawWires`（SVG 贝塞尔连线）+ fitStage 缩放。
- `radial.css` 919 行：**含 40 处硬编码十六进制色**，未接皮肤变量——移植时必须做色板映射（§5）。
- 舞台 1500×1000 无界画布；四卡位置 MN_POS 固定；主卡 hub-slot 在辐射态几何零变化（原型已实测通过）。

## 2. 交互设计

### 2.1 触发口径（与设计文档 §3 定稿一致）

| 场景 | 行为 |
| --- | --- |
| 认词卡选「模糊」/「不认识」 | 评分动作照常执行，**随后**自动展开助记辐射层 |
| 认词卡选「认识」 | 零辐射，照旧自动跳词 |
| 默写卡「判错」/「查看答案」 | 判分/音效照常，随后自动展开 |
| 默写卡判对 | 零辐射，照旧 900ms 自动跳词 |

关键时序：**先落原有状态（揭示释义/判分徽标/写回评分），再叠加展开**——助记层是纯前端叠加，不参与、不阻塞评分写回。

### 2.2 手动开关（额外新增按钮）

- 位置：主卡右上角（`flashcard` 外缘，`recog-stage` 内），圆形小按钮「💡 助记」样式沿用 `play-bare` 弱化态。
- 行为：任意状态可点开/收起（toggle）；已评分回看上一个词时同样可用。
- 显隐：当前词四字段**全缺**时按钮隐藏（无内容不提供入口）；部分缺失时按钮显示、辐射层内缺数据的卡不渲染（沿用原型 `mnHasContent` 逻辑）。

### 2.3 键盘与焦点（不破坏方向键的关键）

- 方向键全局监听**不改**：overlay 打开时 ArrowLeft/Right 仍走 `tryNav`——翻词的同时关闭当前助记层（新词重新评估触发条件，不自动重开）。用户手感：方向键永远=翻词。
- 新增：`Esc` 关闭助记层；overlay 打开时 `Tab` 焦点困在层内（关闭后归还触发按钮）。
- 默写卡输入聚焦时方向键本就不抢键——助记层不引入任何可聚焦输入控件（真实语境卡发音按钮除外），无冲突面。

### 2.4 关闭方式

Esc / 手动开关按钮 / 方向键翻词 / 点击蒙层空白处——四种，均不产生评分副作用。

## 3. 呈现形态：全屏 Overlay 辐射层（推荐定案）

**方案 A（定案）：`position: fixed` 全屏半透明蒙层 + 居中辐射画布（scale 自适配）**

- 打开时：蒙层 `rgba` 压暗背景；辐射画布按 `scale = min(vw/1560, vh/1040)`（留边距）整体缩放居中，画布内**复刻当前词主卡**（同一数据源渲染，与真实主卡视觉一致）+ 四张助记卡 + SVG 连线，stagger 动画照搬原型。
- 关闭时：反向收拢动画后卸载（`display:none` 复位，重开可复用已构建 DOM——原型同款策略）。
- 优点：主卡及其周边（进度条、三键、方向键）**绝对零变化**——被蒙层盖住而非变形；1500×1000 无界画布的原型布局无需任何压缩改版，直接缩放即可；各视口尺寸天然适配。
- 主卡复刻说明：复刻卡与真实主卡共享 `QueueItem` 渲染参数（word/phonetic/image），但独立挂载在画布内，不参与 fitWord/align 逻辑，互不干扰。

**备选 B（否决记录）：卡片下方内嵌展开四宫格**——会推挤三键与方向键对齐（`useLayoutEffect` 需重算 anchor），且四卡横向信息密度放不下，违背「主卡零变化」约束。仅作记录。

## 4. 数据契约（前端侧）

`page.tsx` 的 `WordContent` 接口补充（全部可选，缺即降级）：

```typescript
interface WordContent {
  // ...现有字段不动...
  syl?: { parts: string[]; ipa: string[]; stress: number; secondary?: number[];
          phonemes: { p: string; syl: number; type: "vowel" | "consonant"; desc: string }[];
          combos?: { letters: string; sound: string; desc: string }[]; notes?: string[] };
  morph?: { type: "derived" | "compound" | "blend"; literal: string;
            pieces: { piece: string; kind: string; meaningZh: string; fromWord?: string }[] };
  derives?: { word: string; pos: string; meaningZh: string }[];
  contexts?: { coll: string; collZh?: string; en: string; cn?: string; audio?: string }[];
}
```

降级矩阵（`mnHasContent` 移植）：

| 字段 | 缺失时 |
| --- | --- |
| `morph` | 构词卡不渲染，连线不出 |
| `derives` | 派生卡不渲染 |
| `syl` | 读音卡回退：仅音节字母色块（运行时按 word 粗切或整词单块），无音素层 |
| `contexts` | 真实语境卡不渲染 |
| 全部缺失 | 助记按钮隐藏；触发点不自动展开 |

发音：真实语境卡每句 🔊 优先播 `audio`（`/audio/contexts/{word}_{idx}.mp3`），缺文件回退 `speechSynthesis`（复用 page.tsx 现有 `speakTts`）。

## 5. 移植映射（原型 → React）

| 原型 | 目标 | 说明 |
| --- | --- | --- |
| `radial.js` 词数据 | 删除 | 改吃 `QueueItem.content` |
| `radiateMn()` DOM 动画 | `MnemonicRadial` 组件内 refs + state | stagger 时序/起飞透明逻辑逐行保留 |
| `buildMnContent()` | 同名纯函数（返回 JSX） | hiColl 高亮正则（屈折+`...`通配+兜底）原样移植 |
| `drawWires()` SVG | `<svg>` + 计算坐标 | 布局坐标 MN_POS 常量化 |
| `fitStage()` | `useLayoutEffect` + resize 监听 | `scale` 存 state |
| `radial.css` 辐射相关段 | `mnemonic-radial.css`（独立文件，/learn 引入） | 只搬辐射用到的类，919 行中同卡直出/旧 demo 样式丢弃 |
| 40 处硬编码色 | **CSS 变量映射**（§5.1 主题适配） | 铁律：不得写死色值 |

### 5.1 主题适配（工程铁律）

- 新建 `--mn-*` 局部变量组（卡面/连线/音节块/高亮 mark 等），默认值引用现有皮肤变量（`--card`/`--foreground`/`--primary`/`--muted` 等），映射表在 CSS 文件头注释留档。
- `html[data-theme=night]` 及其余七套皮肤下逐一目检：暗色下连线与卡面对比度、mark 高亮可读性；违反 AA 即加皮肤覆写。
- 动画帧用 `transform/opacity`（合成层），不触发布局。

## 6. 分期实施（2026-09-06 用户定序：生成管线先行，真实数据落地后再上前端）

> 顺序理由：①渲染层没有真实数据就没有验收抓手（原型数据是 mock，样式细节无法证伪）；②数据契约先在真实生成中跑通（校验规则、TTS 音频落盘），前端照实写不返工；③管线问题在脚本层调试比前端联调时发现便宜。

### Stage 1 · 生成管线 + 真实数据导入（先行）

1. 新建 `scripts/gen-mnemonic.mjs`（CLI，复用 config.json 现有 LLM 配置）：
   - 四次独立 LLM 调用（① morph / ② syl / ③ derives / ④ context），prompt 与输出校验按设计文档 §5 定稿模板执行（phonemes 拼合 === ipa 拼合、morph pieces 覆盖整词、coll 可定位等，单路拒收计入重试、失败隔离）；
   - 写回 `words.contentJson` 的 `syl/morph/derives/contexts` 字段（幂等 merge，不碰现有字段）；
   - 调试期完整落盘原始返回（status/usage/原始 JSON 全量存 `data/` 或日志），失败可追溯（外部 API 调试铁律）。
2. TTS 例句音频：contexts 逐句 edge-tts（en-US-EmmaMultilingualNeural --rate=-8%，与现有例句音色一致）→ 落 `public/audio/contexts/{word}_{idx}.mp3` → 文件 >1KB 才回写 `audio` 路径。
3. 导入 2-3 个真实词的全套字段（建议：literature + outbreak + 一个未在原型出现过的词，验证泛化），字段用脚本/SQL 目检核对。
4. 调试入口说明：`node scripts/gen-mnemonic.mjs --word literature [--rebuild]`；「补全助记」按钮与设置界面属 Stage 3，本阶段 CLI 即可。

### Stage 2 · 前端渲染层（真实数据驱动）

1. 新建 `src/components/vocab/mnemonic-radial.tsx` + `mnemonic-radial.css`：Overlay 组件（蒙层/缩放/四卡渲染/连线/stagger 动画/关闭交互）。
2. `page.tsx` 接线（预计 <60 行侵入）：
   - `WordContent` 接口扩四字段；
   - 三个触发点调用 `openMnemonics()`（hard/again、判错、查看答案分支末尾，`setTimeout` 延迟 ~150ms 让原状态先落地）；
   - 主卡右上角手动开关按钮；
   - 键盘：Esc 处理加入现有监听器同款模式（不动 Arrow 分支）。
3. 验收直接用 Stage 1 导入的真实词，渲染、高亮（屈折 + ` ... ` 通配）、audio 播放逐项核对。

**Stage 2 验收清单**：

- [ ] 认词卡：认识→零辐射+自动跳词；模糊/不认识→释义揭示后辐射层展开，主卡（含三键、方向键位置）截图前后像素级不变；
- [ ] 默写卡：判对零辐射+900ms 跳词；判错/查看答案→辐射展开；
- [ ] 方向键在辐射层打开时照常翻词并关闭辐射层；Esc 可关；
- [ ] 四字段全缺的词：无按钮、触发不展开（静默）；
- [ ] 八套皮肤目检（重点 night）；tsc --noEmit 零错误；
- [ ] 真实语境卡：词组句中高亮（含屈折/`...`通配用例）、🔊 audio 优先 + TTS 回退。

### Stage 3 · 配套（P1.6）

- 设置界面（prompt 编辑框 + 恢复默认）、词书详情页「补全助记」按钮 + 进度可视化、批量生成调度（`app_settings.mnemonic.enabled` 总开关）。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| overlay 内复刻主卡与真实主卡视觉漂移 | 复用同一段渲染参数；验收截图对比 |
| 40 处硬编码色在部分皮肤下违和 | `--mn-*` 变量层隔离 + 八皮肤目检进验收 |
| stagger 动画期间快速翻词 | 动画基于组件挂载，翻词即卸载，无残留定时器（原型 cleanup 逻辑一并移植） |
| Edit 类小改动静默失效（本会话前科） | 关键编辑后 grep/读盘复核；大批量结构化改动用 node 脚本断言 |
| 长单词在辐射主卡溢出 | 复刻卡沿用 fitWord 收缩（独立实例，不影响真实主卡） |
